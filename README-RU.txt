Капани — обновлённая статическая версия
27 октября 2026

В архиве — сайт на HTML, CSS и JavaScript без сборщика и серверной части Node.js, объединённый SQL-файл и отдельные миграции. Сохранены настройки Supabase исходного сайта. SQL подготовлен для самостоятельного применения владельцем.

Как обновить существующий сайт
1. Сделайте резервную копию базы.
2. Проверьте в Supabase, что миграции 001–007 и защищённые таблицы Kapani установлены.
3. Проверьте адрес проекта и только после этого запустите INSTALL.sql в SQL Editor. Файл проверяет базовые требования и прерывается, если не найдёт нужную схему.
4. Разверните файлы архива рядом, сохраняя index.html, assets/, functions/subscription-config.js и supabase/. Вход и сохранение данных используют существующий Supabase; карты и библиотека Supabase загружаются из сети.

В INSTALL.sql только добавочные изменения 008–013. Для чистой базы он не подходит; полная базовая установка требует уже настроенных таблиц аутентификации, пользователей, кошелька, ledger и ролей. В архиве нет ключей service-role.

Готово в этой версии
- Исправлено несовпадение очереди заявок «apps/jobApps», добавлено отображение мотивации в мэрии.
- Добавлены публичный просмотр профилей и права КСБ/полиции на чтение паспорта и лицензий.
- В разделе «Работа» сохранена прежняя анкета сверху; ниже — список профессий с плавно раскрывающимися обязанностями, оплатой и требованием КВЭ.
- Новый зал казино с четырьмя играми, отдельным балансом и серверным случайным результатом.
- Добавлены события ставок, отдельное окно «Мои записи», карта такси и доставки, карточки объявлений, чек банковского перевода и основные действия с сообщениями. Убрана заметка «Капани больше не работают».

Что осталось
- SQL не применялся к действующей базе по просьбе владельца. Требуется после применения проверить живой Supabase и права ролей.
- Нет полного теста всех 16 разделов с реальными аккаунтами и сценария «купил объявление → заказал доставку → отменил → заказал повторно → подтвердил».
- Такси считает прямое расстояние по карте; не дорожный маршрут. Автоматическое назначение, live GPS и полный цикл оплаты ждут проверки на живом сайте.
- Не завершены полная переработка профиля по референсам, весь дизайн и полный мобильный тест Telegram-подобного чата, все сценарии аренды, уведомления и финансовые процессы бизнеса, общая балансировка зарплат/цен.
- Новый игровой счёт начинается с нуля; старый баланс казино автоматически не переносится.

Проверки, выполненные до упаковки
59 локальных проверок SQL-сценариев/денежных переходов; 9 тестовых экранов без ошибок JavaScript; синтаксис 265 обработчиков; 12 регрессионных проверок банка, заявок, доставки и KSB. Проверки изолированы от рабочей базы и не подтверждают поведение действующего Supabase.
