Капани — лесное оформление, версия 26 октября 2026 года.

Сайт сохранён на прежнем стеке Firebase Auth/Realtime Database, Cloudflare Worker и GitHub Pages. Содержимое, имена разделов, идентификаторы элементов, обработчики и пути к данным, кроме отдельно оговорённых изменений, сохранены. Дополнительный файл `assets/kapani-forest.css` загружается после старых тем. Два фоновых изображения `assets/forest-road.webp` и `assets/village-street.webp` лежат локально и не требуют сторонних изображений по сети. Главная стала компактнее, быстрые действия разбиты на смысловые группы, карта сворачивается. На телефонах остаётся нижняя навигация, на широких экранах используется боковая панель.

Загрузочный экран теперь показывает анимацию роста ели, затем надпись «Капани» и статус загрузки. При включённом в системе уменьшении движения анимация не навязывается. В мэрии убрана вкладка «Оформление» и оставлены шесть рабочих направлений.

Для исправленной отмены заказа таксистом нужно разместить новые файлы сайта на GitHub Pages и отдельно опубликовать Cloudflare Worker из `push-worker/worker.js` с помощью `cd push-worker` и `wrangler deploy`. Если вы редактируете Worker прямо в панели Cloudflare, используйте `push-worker/worker-bundled.js`, в который исправление тоже добавлено. Уже опубликованный Worker не обновится сам при загрузке HTML. Отказ таксиста доступен в состояниях принятия заказа, подъезда к клиенту и самой поездки. Он атомарно возвращает заказ в очередь и снимает с водителя не более 35 рублей, не уводя баланс в минус. Запрос проверяется по действующему паролю/хэшу аккаунта на сервере. Никакие новые права на запись заказов и балансов из браузера не выдаются. Firebase Functions для этого не нужны; тариф Spark подходит.

Проверки запускаются командами `node tests/forest-redesign.test.cjs`, `node tests/client-smoke.cjs`, `node tests/mayor-navigation.test.cjs`, `node tests/worker-admin-claim.test.cjs` и `python3 tests/validate-syntax.py`. Они проверяют маршруты и запуск клиента в мок-среде, синтаксис, сохранённые действия, обе версии Worker, проверку владельца заказа, повторную отмену и штраф. Тесты, рассчитанные на старые API (`client-state.test.cjs` и `worker.test.cjs`), не проходили и в оригинальном архиве до изменений.

Тестовая среда не подключалась к вашим реальным аккаунтам и живой базе, поэтому запись поездки, приход push и отображение на физическом телефоне нужно проверить после публикации. Для этой сборки используются новые исходники из архива, а старые вложенные ZIP-резервные копии и старые временные файлы с возможными секретами специально не включены в итоговый ZIP.

Дополнение к оформлению. Файл `assets/kapani-forest-finishes.css` подключён последним и добавляет сложные градиенты для карточек, кнопок, мэрии и навигации. Plus выполнен в оттенках лесного мёда и мха, Ultra — в бирюзово-изумрудных, Prime — в переливающихся золотистых, хвойных и туманных голубых оттенках. Перекрытие прежних персональных цветов в профиле и сообщениях исправлено, все старые варианты остаются доступными по прежним идентификаторам.

В настройке профиля появились шесть согласованных наборов, каждый с отдельной рамкой, фоном профиля и цветом сообщения. «Мох и хвоя» и «Лесной луг» доступны с Plus, «Хвойные сумерки», «Дыхание природы» и «Янтарный зверь» — с Ultra, «Буря тайги» — с Prime. Prime включает также все предыдущие варианты. Выбор можно посмотреть во встроенном примере до сохранения. Отмена изменений возвращает сохранённый облик. Сетка подписок и основных разделов теперь имеет отдельные правила для планшетов, телефонов и экранов уже 390 пикселей, а анимации учитывают настройку уменьшенного движения.

Новые проверки — `node tests/forest-visuals.test.cjs`. Они проверяют регистрацию всех 18 частей новых наборов, доступность вариантов для каждого уровня подписки, восстановление старых стилей, систему градиентов и мобильные медиаправила. Это проверки исходного кода и моков, а не визуальное тестирование на физических устройствах.
